# TaskFlow AI 🚀

A modern React-based task management application to organize tasks, track progress, and boost productivity.

## ✨ Features
- Add, edit and delete tasks
- Work, Personal and Study categories
- Set task due dates
- Mark tasks as completed
- Search and filter tasks
- Drag-and-drop task reordering
- Data persistence using LocalStorage
- Responsive dashboard UI

## 🛠️ Tech Stack
- React.js
- JavaScript
- HTML5 & CSS3
- Vite
- LocalStorage

## 🚀 Run Locally

```bash
git clone https://github.com/ranjitiwale/TaskFlow-AI.git
cd TaskFlow-AI
npm install
npm run dev
```
