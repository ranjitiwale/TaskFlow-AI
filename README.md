# 🚀 TaskFlow AI – Smart Task Management Application

A modern and responsive task management application built with React.js to organize daily tasks, manage productivity, and track progress efficiently.

## 🌐 Live Demo
[View TaskFlow AI](https://task-flow-ai-seven.vercel.app/)

## 💻 GitHub Repository
[View Source Code](https://github.com/ranjitiwale/TaskFlow-AI)

## ✨ Features
- Create, edit, and delete tasks
- Organize tasks into Work, Personal, and Study categories
- Set task due dates
- Mark tasks as completed
- Filter tasks by status
- Search tasks
- Drag-and-drop task reordering
- Save tasks using Browser LocalStorage
- Responsive dashboard interface

## 🛠️ Tech Stack
- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- Vite
- Browser LocalStorage

## ⚙️ Installation & Setup

```bash
git clone https://github.com/ranjitiwale/TaskFlow-AI.git

cd TaskFlow-AI

npm install

npm run dev
```

Open `http://localhost:5173` in your browser.
